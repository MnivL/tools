# MnivL Tools

个人工具集合。每个重要项目维护在独立 GitHub 仓库中，这里只维护索引，避免同一份代码出现多个来源。

## 工具索引

| 工具 | 说明 | 独立仓库 |
|---|---|---|
| any2excel | 将 JSON / JSONL 数据转换为 Excel，支持大文件流式处理和 Excel 分片 | [MnivL/any2excel](https://github.com/MnivL/any2excel) |

## 维护约定

- `tools` 仓库只保存工具索引、说明和集合级配置。
- 需要独立展示、测试、发布或面试介绍的项目，使用独立仓库维护。
- 不在这里复制独立项目的完整源码。
